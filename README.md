One AI-generated joke about office life, written to `/output/entry.txt`:

> HR approved an AI assistant for morale. It now sends Dave from accounting the same sympathy GIF every Monday.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```

## How it works

`main.py` composes the joke, asserts it stays under 200 characters, creates `/output/` if needed, and writes the joke to `/output/entry.txt`.
